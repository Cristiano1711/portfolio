# cristiano.dev

Meu portfólio pessoal. Sou **Cristiano Cardoso**, estudante de Engenharia de Software na UFAM, focado em automação, dados e IA.

🔗 Site: [portfolio-cristiano-cardoso.vercel.app](https://portfolio-cristiano-cardoso.vercel.app/)

## Sobre

Esse portfólio é, antes de tudo, um registro do meu aprendizado — cada projeto listado aqui é uma etapa real do processo, não um produto final e polido. O design segue uma estética de terminal/IDE dark, com um painel de "log" simulando meu pipeline de aprendizado em andamento.

## Stack

- HTML5 semântico
- CSS puro (variáveis CSS, grid, flexbox, animações)
- JavaScript vanilla (só pra atualizar o ano no rodapé)
- Fontes: [Inter](https://fonts.google.com/specimen/Inter) e [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
