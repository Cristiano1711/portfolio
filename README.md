# cristiano.dev

Portfólio pessoal de **Cristiano Cardoso**, estudante de Engenharia de Software na UFAM, focado em automação, dados e IA.

🔗 Site: adicione aqui o link do GitHub Pages, se estiver ativo (ex: `https://cristiano1711.github.io/portfolio/`)

## Sobre

Este portfólio funciona como um registro de aprendizado — cada projeto listado é uma etapa real do processo, não um produto final e polido. O design segue uma estética de terminal/IDE dark, com um painel de "log" simulando um pipeline de aprendizado em andamento.

## Stack

- HTML5 semântico
- CSS puro (variáveis CSS, grid, flexbox, animações)
- JavaScript vanilla (apenas para o ano dinâmico no rodapé)
- Fontes: [Inter](https://fonts.google.com/specimen/Inter) e [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)

## Rodando localmente

Não há build nem dependências. Basta clonar e abrir o arquivo no navegador:

```bash
git clone https://github.com/Cristiano1711/portfolio.git
cd portfolio
```

Depois é só abrir `index.html` direto no navegador, ou servir a pasta com qualquer servidor estático:

```bash
python3 -m http.server 8000
```

e acessar `http://localhost:8000`.
